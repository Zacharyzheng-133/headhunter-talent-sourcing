# Screening Rubric — 候选人筛选与评分

## 一票否决（先过这关，再谈评分）

| 条件 | 说明 |
|---|---|
| 时间窗不符 | 毕业时间超窗（晚于目标届数）或经验年限超窗。擦边都不放——客户明确要 26 届，27 届就是 0 分 |
| 学历不符 | 要求博士的岗位，硕士直接出局（除非工程能力极强且用户明确放宽） |
| 刚入职 | 入职新公司 <6 个月的，挖动概率极低，进长线池 |
| 方向零交集 | 简历方向词与岗位方向无交集（如纯理论统计 vs 工程型 post-training 岗） |
| 匿名化冲突 | 见下方风险检查 |

## 加权评分表

过否决线后按六维打分（每项 0-100），加权求和：

| 维度 | 权重 | 高分特征 | 低分特征 |
|---|---|---|---|
| 学历背景 | 15% | 顶校/强实验室博士，名导师 | 普通院校，方向不明的导师 |
| 毕业时间 | 20% | 正好目标届/目标经验年限 | 超窗（本应先被否决，擦边情况在此扣分） |
| 方向对口度 | 30% | 岗位关键词逐字命中（如岗位要 RSI，候选人主页标题就是 self-improving） | 相邻方向，需迁移（如 AI4Science 的 RL vs 通用 Agent 的 RL） |
| 工程与技术栈 | 20% | 分布式训练、RL 框架实操、工业实习、成本优化经验 | 纯理论、无实习、无开源 |
| 论文质量 | 10% | 顶会一作、高引用、被工业界采用 | 非顶会、低引用、方向漂移 |
| 地理适配 | 5% | 目标城市在读/有回国意愿 | 地理冲突且无意向信号 |

参考分数线：**80+ 立即推，60-80 补信息后再定，<60 不推**（时间窗导致的低分单独处理：进长线池）。

## 风险与疑点清单（推之前必须过一遍）

打分之外，以下问题必须核实或在沟通中问清，不要让客户自己发现：

1. **主线方向偏移**：代表作方向与岗位方向的差异（如符号回归 RL vs 通用 agent post-training），技术面要问迁移思路
2. **零工业界经验**：全学术背景的候选人要评估出货速度
3. **毕业/入职时间矛盾**：主页挂 job market 但按学制远未毕业——是提前毕业、找实习、还是要退学？第一通电话必须问
4. **回国/换城市意愿**：海外候选人回深港是重大决策，别假设愿意
5. **被大厂锁定**：正在头部实验室实习的（如头部 Seed 团队），大概率被 return offer 锁定，动作要快且备好差异化卖点（股权、核心位置）
6. **竞对态势**：主动求职的候选人大概率同时在聊多家，问清手上进度

## 匿名化风险检查（客户身份保密时必做）

候选人触达前，检查其社交/学术网络与客户背景的交集：

- **导师/带教重叠**：候选人的导师、实习带教是否与客户创始人/高管是前同事？是 → 候选人一提机会，客户身份当场暴露
- **现雇主重叠**：候选人正在客户创始人前东家实习/工作 → 最高风险，暂缓触达，等其离职或客户放开身份
- **处置**：中风险者在邮件/微信中收紧口径（不提创始人背景，统一说"早期技术型公司"）；高风险者留档并记录暂缓原因

## 背景核实清单（信息不全时逐个补）

- [ ] 毕业时间（主页 > 导师组页面 > LinkedIn > 直接邮件问）
- [ ] 导师与实验室
- [ ] 一作论文与发表 venue
- [ ] 实习/工作经历与时间线
- [ ] 求职状态声明（job market / seeking / 无）
- [ ] 引用量（Google Scholar，判断学术影响力）
- [ ] 技术栈与工程信号（开源贡献、实习内容）
- [ ] 地理与身份（在读地、国籍倾向、base 接受度）
